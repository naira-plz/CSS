# Gaming News 

Gaming News es una página web sobre videojuegos que he creado utilizando HTML y CSS. En ella se pueden encontrar noticias y novedades de diferentes juegos, como Minecraft, Fortnite y Roblox, además de información sobre el mundo gaming y los eSports.

## ¿Qué incluye la página?

- Una cabecera con el nombre de la página.
- Un menú para navegar por las distintas secciones.
- Una noticia principal sobre Minecraft.
- Cuatro noticias sobre diferentes temas gaming.
- Una sección de noticias destacadas.
- Un apartado de contacto.

## Tecnologías utilizadas

- HTML para crear la estructura de la página.
- CSS para darle diseño y estilo.
- Bootstrap para organizar algunos elementos y facilitar el diseño.

## Herramientas

He utilizado Visual Studio Code para realizar el proyecto y GitHub para guardar los cambios.
